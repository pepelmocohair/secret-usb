# SECRET.usb（仮）

地下室のエリオットと、引き出しの奥のUSBメモリが、世界を管理するAIを止める話。
戦闘なしの探索アドベンチャー。

## 遊び方
`index.html` をブラウザで開く。サーバーは要らない。

| 操作 | キー |
|---|---|
| 歩く | 矢印キー / WASD |
| 調べる・セリフを送る | Z / Enter / スペース |
| 選択肢を選ぶ | ↑↓ ＋ 決定 |

スマホでは画面下のボタンを使う。

## 対応ブラウザ
最新版の Chrome / Edge / Firefox / Safari。

## いまの範囲
第2章「馬鹿」（エリオットがUSBを挿すところ）まで遊べます。続きはできしだい、ここに足していきます。
